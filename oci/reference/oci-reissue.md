## When this applies (embassy list)
| Trigger | Service |
|---|---|
| New passport issued **after completing age 20**, card obtained before 20 — once | Re-issue |
| Name change (any reason, incl. marriage) | Re-issue |
| Change of nationality (not to Pakistan/Bangladesh) | Re-issue |
| Error on the card / change of personal particulars needing a new card (father's name, DOB correction) | Re-issue |
| Lost or damaged card | Re-issue, higher fee |
| New passport under 20, or once after 50; address / occupation change; foreign-spouse new passport | **Upload only, free** — not this file |

## Preconditions
- Passport valid **≥ 6 months** at submission (this checklist; the fresh-OCI minor and spouse checklists say 9).
- On ociservices.gov.in choose **OCI Miscellaneous Services**, not New Registration. "Re-Print Submitted Application" is only for reprinting a form already filed.
- Photo + signature JPEGs to spec before starting (`photo-specs.md`); print and upload identical; signature matches passport. Minor under 5 → left thumb (Govt instructions; the VFS re-issue checklist is silent).
- Name change: the **previous name must be entered** on the form, and the change document (court order / notarized affidavit; marriage certificate for a married name) scanned.
- Supporting PDFs ≤ 1000 KB each, one per category; all uploaded or the file is returned unprocessed.
- **You send the original OCI card.** Do not book travel to India on it during processing. From 8 July 2026 what comes back is an e-OCI on the portal, not a new booklet — the surrendered card is not returned as a travel document (UNVERIFIED whether VFS mails the cancelled card back).
- Lost card: the VFS checklist lists **no** police report. Some consulates ask for one or a notarized loss affidavit — condition-based, check `gotchas.md` for the centre; have one ready, do not assert it is required.

## Listed rejection causes
Identical to the fresh-OCI list (poor photo/signature; uploads missing; wrong passport number or issue date; wrong name/POB/DOB; parents'/spouse's names not matching current legal names; marital status missing; wrong contact; Part B unsigned; **previous name omitted**; ZIP missing; native address proof missing). For re-issue the live one is #9: a married name on the new passport with no "previous name" entered.

## Processing time
- VFS: none stated.
- CGI Chicago: **6–7 weeks** for "re-issuance/updation" from consular registration, subject to MHA clearance. Other consulates publish nothing; use 6–8 weeks and track on ociservices.gov.in → Status Enquiry.
- Incomplete application not fixed within **20 calendar days** → returned, consular + ICWF refunded minus postage. Additional documents requested by the consulate not supplied within **7 calendar days** → processing may stop, no refund.

## Travel during re-issue
The embassy page allows travel on the existing card + new passport only for the *upload* cases. For re-issue you have surrendered the card; if travel is unavoidable, apply for an Entry visa (`visa-spouse.md` covers the X-visa stack) rather than counting on the e-OCI date.
